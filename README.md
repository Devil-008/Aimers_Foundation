# Aimers Foundation - Professional Portfolio Website

A modern, responsive, and professional portfolio website for Aimers Foundation, showcasing educational services, facilities, and contact information.

## ✨ Features

### 🎨 Modern Design
- Professional and clean user interface
- Smooth animations powered by Framer Motion
- Responsive design for all device sizes
- Modern gradient backgrounds and shadows

### 📱 Fully Responsive
- Mobile-first approach
- Optimized for phones, tablets, and desktops
- Touch-friendly navigation
- Adaptive layouts and components

### 🚀 Performance Optimized
- Fast loading times
- Smooth scrolling and animations
- Optimized images and assets
- SEO-friendly structure

### 🎯 Key Sections
1. **Hero Section** - Eye-catching introduction with key services

## 📦 Installation & Setup

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn package manager

### Installation Steps

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd aimers-foundations
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```

5. **Preview production build**
   ```bash
   npm run preview
   ```
